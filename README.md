# 🍱 FoodLoop

### Turning surplus food into shared resources.

FoodLoop is a web-based platform designed to help reduce food waste by connecting people and organizations with surplus food to those who can make use of it.

The project focuses on creating a simple digital platform where surplus food can be listed, discovered, and redistributed instead of being unnecessarily discarded.

---

## 🌱 About the Project

Every day, usable food can become surplus due to restaurants, events, households, or other food providers having more food than they need.

FoodLoop aims to address this problem by providing a platform where users can share information about available surplus food and help connect it with potential recipients.

### Our Vision

> **Share what you have. Reduce what gets wasted.**

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/foodloop.git
```

### Navigate to the Project

```bash
cd foodloop
```

### Install Dependencies

```bash
cd backend
npm install
```

### Run the Project

```bash
npm start
```

If the project uses a development script:

```bash
npm run dev
```

The terminal will display the local address where the application is running.
